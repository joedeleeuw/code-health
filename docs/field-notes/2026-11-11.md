# 2026-11-11

## Rust engine removal (`a19a5d2`): review findings and fix-forward estimate

`a19a5d2` deleted the tree-sitter Rust engine and moved Rust checks to Clippy thresholds and ast-grep rules. It landed without a review. A Gemini 4 Carbon (high) review of intent against the landed state followed; the rows marked "reproduced" were rerun by the author on real projects.

Corrections to the commit message:

- "a copy of cloud-rl-train reports no Rust finding" proves nothing: every Rust file there is under an excluded folder, so no Rust was measured.
- The 313-versus-28 suppression figure counts only `allow(clippy::...)`. The lint that was switched on fires on every unexplained `allow`; counted that way the corpus is 385 per 1000 files in agent-written Rust and 80 in mature Rust.
