# 2026-11-12

## A rule must separate the groups across the corpus, or it goes

`host-path-rust` (0.0 per 1,000 files in agent-written repositories, 0.3 in mature ones) and `reexport-module-rust` (1.8 against 1.6) are deleted: neither fires more often in agent-written code. A first adopter found the same thing from the other side, where every `host-path-rust` hit was sample data in UI preview code.

`blocking-in-async-rust` no longer reports blocking calls inside an async block handed to a background executor (`background_spawn(async { .. })`, `background_executor().spawn(async { .. })`) or inside `unblock`. That is the place such calls belong. Its rate stays at 31.1 per 1,000 files in agent-written repositories and falls from 5.4 to 3.6 in mature ones.

## Review changes to the Python rules

- `revalidation-isinstance-typed-param` is not shipped. A second grader put it at 11 of 15: it reports runtime validation of public API arguments, checks in decorated and nested functions, and `NotImplemented` guards in in-place operators.
- `source-guard-test` skips reads under a temporary directory, which are generated output and not repository source.
- `stringly-state` reads the `default=` argument of `Field(...)` as syntax; text inside other arguments no longer matches. Its message no longer claims the values are closed.
- `test-imports-private` reports every private name in an import list, not only the first.
- The opt-in rule tests run in the commit gate through `code_health/sgconfig-off.yml`.
